# Tools

This build does not require a machine shop, but it does need careful mechanical assembly and wiring.

## Minimum Bench Tools

| Tool | Why |
|---|---|
| Metric hex key set | M2/M3/M4 socket screws |
| Metric nut driver or socket set | Nuts and locknuts |
| Digital calipers | Measuring printed fits, bearings, shafts, and hole cleanup |
| Flush cutters | Filament, zip ties, small wire |
| Hobby knife / deburring tool | Cleaning printed edges and holes |
| Needle files and sandpaper | Fitting bearings, shafts, and printed interfaces |
| Temperature-controlled soldering iron | Wiring, headers, heat-set inserts |
| Wire stripper | Clean wiring work |
| Digital multimeter | Continuity checks, voltage checks, short checks |
| Helping hands or PCB holder | Easier soldering and connector assembly |

## Strongly Recommended

| Tool | Why |
|---|---|
| Ferrule crimper kit | Safe screw-terminal wiring |
| JST/DuPont crimper | Custom sensor and signal cables |
| Small drill/driver | Cleaning holes and mounting brackets |
| Metric drill bit set | Hole cleanup for M2/M3/M4/M5 hardware |
| M3/M4/M5 tap set | Thread cleanup or threaded printed/metal parts |
| Small clamps or bench vise | Pressing bearings and inserts |
| Safety glasses | Drilling, clipping, soldering, and powered tests |

## Consumables

- Heat-shrink tubing
- Zip ties
- Electrical tape
- Blue threadlocker
- Isopropyl alcohol
- Super glue or epoxy
- Solder
- M3/M4/M5 heat-set inserts
- Wire ferrules
- 22 AWG and 18 AWG stranded wire

The multimeter is not optional. Every power-up should start with checking polarity, voltage, and continuity before the controller or drivers are connected.
